# AhhLog

A personal engineering blog focused on software development,
engineering principles, architecture, and the reasoning behind
technical decisions.

## About

AhhLog is a personal project where I write about software engineering,
programming principles, architecture, design patterns, C#/.NET,
and the reasoning behind technical decisions.

The goal isn't to provide absolute answers.

It's about asking better questions:

- Why should I use this design pattern?
- When does an abstraction actually help?
- When is a struct a better choice than a class?
- Is Clean Code always clean?
- When does architecture become overengineering?
- What trade-offs am I making with this decision?
